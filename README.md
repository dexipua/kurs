# Мій курс

Скіл для [Claude Code](https://claude.com/claude-code), який робить тобі особистий трекер розвитку з ігровим шаром і нагадуваннями від Claude на телефон.

- **Трекер** — приватна сторінка на claude.ai: щоденні звички, задачі з дедлайнами, великі цілі з кроками, режим сесії.
- **Гра** — досвід за кожну дію, рівні, ранги від E до S, характеристики (Інтелект, Сила, Мудрість…), щоденний і штрафний квест, досягнення.
- **Тренер** — Claude пише план зранку, перевіряє ввечері й робить розбір тижня в неділю. Сповіщення приходять у застосунок Claude на телефоні, навіть коли комп'ютер вимкнений.
- **Налаштування словами** — прямо на сторінці є поле «Сказати Claude»: пишеш «додай звичку бігати 3 рази на тиждень» чи «я захворів, полегши план на 3 дні», і він сам усе змінює.
- **Англійська з Claude** — коротка розмова голосом або текстом, як на співбесіді: Claude виправляє помилки, а наприкінці дає фідбек і орієнтовний рівень.
- **Принцип дня** — щодня одна коротка ідея про людей і себе (за мотивами Карнегі й Гріна).
- **12 тем оформлення** — Море, Ліс, Захід сонця, Система, Сакура, Графіт, Неон, Пісок, Лаванда, Кава, Північне сяйво, Рубін; світлий або темний режим, гострі чи круглі кути, просторо чи компактно, 4 шрифти.
- **Календар** — місяць, де кожен день підсвічений за виконаними звичками; можна відмітити звичку за минулий день і запланувати задачу на будь-яку дату; підсумок місяця.
- **Дрібниці** — серії для кожної звички, фільтр задач за напрямом, гарячі клавіші на комп'ютері (1–6 вкладки, N нова задача, F фокус 25 хв).
- **Фокус-таймер** — 10, 25 або 50 хвилин без відволікань, кожні 2 хвилини дають досвід у «Фокусі».
- **Анімації** — плавні переходи між вкладками, «підскок» галочки, конфеті за виконаний квест і новий рівень; усе вимикається, якщо в системі ввімкнено «менше руху».
- **Будь-який екран** — телефон, планшет або комп'ютер (на широкому екрані дві колонки).

## Що потрібно

- [Застосунок Claude](https://claude.com/download) для комп'ютера (вкладка Code) з підпискою.
- Застосунок Claude на телефоні з тим самим акаунтом — щоб приходили сповіщення.

## Встановлення

У Claude Code напиши по черзі:

```text
/plugin marketplace add dexipua/kurs
/plugin install kurs@kurs
```

Потім просто попроси: **«Налаштуй мені Мій курс»**. Claude поставить кілька питань (ім'я, що хочеш розвивати, о котрій нагадувати), створить сторінку, заповнить її під тебе й налаштує нагадування.

## Приватність

Сторінка й дані живуть у твоєму акаунті Claude. Доступ до даних має лише власник, навіть якщо посилання хтось побачить. Нагадування — це запуски Claude у твоєму ж акаунті й витрачають твій ліміт, як звичайні повідомлення (три коротких запуски на день).

## English

A Claude Code skill that sets up a private habit, task and goal tracker on claude.ai with an RPG-style layer (XP, levels, ranks E–S, daily and penalty quests, achievements) and scheduled Claude coaching pushed to your phone. The interface is in Ukrainian. Install with the two commands above, then ask Claude to set up «Мій курс».
